# San Francisco Bay – Public Metocean Data

Interactive map of public wave, current and water-level data for San Francisco Bay
(NOAA NDBC, Scripps CDIP, NOAA CO-OPS, USGS). Built with Leaflet and Plotly.

This repository only hosts the static site (GitHub Pages). Each station panel lists its
data source, period and license; every chart tab can export its data as CSV.
